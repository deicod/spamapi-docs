Getting Started¶

This guide walks through verifying an API key and checking content for spam.

Base URL¶

  • https://spamapi.de

Authentication¶

Use an API key in the request header:

  • X-API-Key: spa_...

Replace spa_... with a SpamAPI key from the dashboard. Stripe keys beginning with sk_live_ or sk_test_ cannot authenticate SpamAPI requests.

Verify Key¶

POST /api/v1/verify-key

{
  "api_key": "spa_..."
}

Check Content¶

POST /api/v1/check

{
  "blog": "https://example.com",
  "user_ip": "203.0.113.10",
  "user_agent": "Mozilla/5.0",
  "comment_content": "Buy cheap pills...",
  "is_test": false
}

Response includes:

  • is_spam (boolean)
  • score (0..1)
  • recommendation (allow, review, discard)

If classification is unavailable, the API returns 503 with error: "detection_unavailable" and no decision. Handle this error explicitly; it does not indicate HAM and does not consume classification usage.

Rate Limits¶

When rate limiting or usage limits apply, the API responds with 429 and a JSON error payload.
