SpamAPI documentation¶

SpamAPI checks comments and form submissions for spam. Connect a WordPress site with the plugin, or call the REST API from your own code. Both use the same account, API keys and monthly checks.

Get started¶

To check… Follow
WordPress comments, Contact Form 7, Gravity Forms or WPForms WordPress setup
Submissions from your own website or app REST API quickstart

Both start with a free account and an API key. Not sure which one fits? Compare them on the integrations page.

Reference¶

  • API reference: endpoints, request fields and responses.
  • Errors and limits: error codes, rate limits and monthly checks.
  • Test mode: test values that skip classification.
  • Troubleshooting: common problems with the API and the plugin.
  • Security policy: supported versions and vulnerability reports.

Downloads¶

  • SpamAPI Anti-Spam plugin ZIP for the WordPress admin; see the setup guide.
  • OpenAPI specification.
  • Integration examples in Go, JavaScript, PHP and Python. Each reads your key from the SPAMAPI_KEY environment variable. The JavaScript example uses Node.js 24's built-in fetch:
SPAMAPI_KEY=spa_... node node.js
